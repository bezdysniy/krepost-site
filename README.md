# Цифровая крепость: словарь кибербезопасности

Интерактивный учебный сайт-словарь терминов кибербезопасности: 9 терминов с примерами, квиз для закрепления и раздел «Культура речи» — как говорить о безопасности точно.

Это статический сайт (один файл `index.html`). Публикуется на GitHub Pages напрямую из ветки `main`.

## Публикация

1. Запушьте эту папку в ветку `main` репозитория.
2. GitHub → Settings → Pages → Source: **Deploy from a branch** → ветка **main**, папка **/ (root)**.
3. Сайт будет доступен по адресу `https://<username>.github.io/<repository>/`.
